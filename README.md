# CFNext 订阅管理器

> 部署在 Cloudflare Workers / Pages 的代理订阅管理面板，单文件同时实现 VLESS / Trojan / XHTTP 多协议代理与图形化配置：`/UUID`（或自定义路径）进入面板，`/sub` 输出订阅；内置节点优选器、节点数量控制、轮询下发、ECH 加密、落地与出站代理及地区 / 运营商 / IP 版本多维筛选，并新增 **MASQUE / 家宽** 三种节点模式与**前后端分离**部署形态。部署即用，绑定 KV 后改完即生效。

# 更新日志 _V2.8.0

## ✨ 新增功能

### 1. 反代 / 落地（ProxyIP）由单值升级为多源，按节点落地国家自动匹配

旧的用法不变：留空 ⇒ 直连失败后走内置地区出口；只填一条 ⇒ 与旧版行为完全一致（全部节点都走这一条）。

**新能力**：允许一次填多条，用英文逗号分隔（分号、换行同样识别），例如：

```
Proxy-HK.SenflareLink.Kdns.fr,Proxy-TW.SenflareLink.Kdns.fr,Proxy-JP.SenflareLink.Kdns.fr
```

下发节点时自动按节点落地国家挑选对应的 ProxyIP —— 香港节点走香港的 ProxyIP、台湾节点走台湾的、日本节点走日本的。

**匹配规则（三条，按优先级）**：

1. **带国家码的条目**：从域名里提取两位国家代码（如 `Proxy-HK.…` 里的 `HK`），只用于该国节点（此处"国家" = 请求实际落地的机房国家）
2. **无国家码的条目**：作为通用候选，按填写顺序 —— 任何国家都可使用
3. **全不匹配**：退回列表首条（此规则同时保证了「只填一条时全局生效」）

**条目类型：域名或纯 IP 都支持**

| 写法 | 示例 | 行为 |
| --- | --- | --- |
| 域名（带国家码） | `Proxy-HK.a.com` | 只用于香港节点 |
| 域名（无国家码） | `proxy.example.com` | 通用候选 |
| 纯 IPv4 | `43.132.231.159:443` | 通用候选（不做 DoH，直连该 IP） |
| 纯 IPv6 | `[2001:db8::1]:443` | 同上（IPv6 必须加方括号） |
| IP + 国家码（前缀式） | `HK.43.132.231.159:443` | 只用于香港节点 |
| IP + 国家码（后缀式） | `43.132.231.159:443#HK` | 只用于香港节点 |
| 多IP + 国家码（写法） | `43.132.231.159:443#HK,43.132.231.159:443#JP` | 用于香港和日本节点 |
### 2. 「密码」支持用环境变量强制覆盖（`ADMIN`）

变量名：`ADMIN`（大小写均可，小写 `admin` 等价；同时存在时 `ADMIN` 优先）。

行为：只要设置了该环境变量，KV `config.admin` 里固化的旧密码一律被忽略 —— 忘记面板密码时可用它强制重置；未设置时仍沿用 KV 中的密码，存量部署行为逐字节不变。

### 3. 新增「配额安全 → 严格模式」

- **开启**：当日用量高于 95% 时，订阅停止下发任何节点（返回 403 与明确提示，次日自动恢复）；
- **关闭（默认）**：完全沿用原有的 60% 起按比例收缩策略；
- **两者互不影响**：同时开启时，超过 95% 由严格模式硬停，未超过则走比例收缩。

### 4. 代码新增「身份 + 字节双随机/双唯一」用户无感

# 更新日志 _V2.3.0（祝各位国庆快乐！）

## ✨ 更新内容

- **节点连接提速（出站并发竞速）直连与内置地区反代改为并发发起，取最先握手成功的，败者连接立即释放。原先「串行尝试 + 逐级超时」会在目标站走 Cloudflare 时白等约 6 秒（直连被 Workers 回环保护拦截），现在反代同时进行，通常 1 秒内即可用。各出站模式（仅代理 / 不走代理 / 默认）的优先级语义保持不变。
- **WS 0-RTT 早数据（ed=2048）**&#8203;：TLS + WebSocket 节点链接（VLESS / Trojan 链接、Clash、sing-box）自动携带 `?ed=2048`，客户端可在 WebSocket 握手阶段预发首个数据包，服务端在握手时即取出并抢先建连，省去一个往返（约 1 个 RTT），明显改善测速、网页首包等握手敏感场景。服务端只接受能通过协议校验的数据，解析失败静默回退，对不支持的客户端零副作用。

- **保底节点前置**：实测高存活 IP（「优选IP-Sxx」「内置·保底-XX」「隧道前置-XX」）恒定保留在清单头部，组内仍随机轮换（首节点永远是稳定节点，但不是固定）；其余节点整体乱序。避免这批最稳的节点在节点数封顶时被顺序截断砍掉，也保证客户端「取第一个」就是可用节点。关闭负载均衡时只做前置、不打乱，语义不变。
- **家宽「隧道前置」节点自动生成**：家宽节点依赖「隧道前置」拨号，而隧道过去取自会被协议开关 / 筛选清空的结果，导致只开家宽的用户拨号链断裂。现在隧道节点固定为 VLESS + WS + TLS(443)，由 Worker 从内置实测可用 CF 段直接生成，不再受面板协议开关、地区 / 运营商筛选与优选源影响，保证家宽始终有可拨号入口。

## 三、代码形态与版本

当前代码共 **六种形态** 各形态代码部署方式如下：

| 形态        | 文件名称                         | 部署目标        | 说明                                       |
| --------- | ---------------------------- | ----------- | ---------------------------------------- |
| 单文件·明文版   | `CFNext-明文版.js`       | Worker      | 面板 + 后端一体，源码可读，**仅供阅读 / 二次开发，不建议直接部署**   |
| 单文件·小说混淆版 | `CFNext-小说混淆版.js`     | Worker      | 面板 + 后端一体，正文嵌入语料、占比约 66%，体积最大            |
| 单文件·Pages | `CFNext-小说混淆Pages版.zip` | Pages（高级模式） | 单文件混淆版打包为 `_worker.js`，走 Pages 通道        |
| 分离版·后端    | `CFNext-后端Worker版.js` | Worker      | 纯节点 / 订阅 / `/api/*`，**无面板、无登录**          |
| 分离版·前端    | `CFNext-前端Pages版.zip` | Pages（高级模式） | 面板 UI + 登录 + 多后端管理 + 聚合下发                |

> **前后端分离版**：前端 Pages 负责面板 / 登录 / 多后端（可跨账户），后端 Wo*rker 只存参数、生成订阅；前端把 `/<入口>/api/*`、`/<入口>/sub/*` 映射到后端并注入 API 密钥。后端不暴露任何独立入口，只能经前端访问*。  
> **单文件版**：面板与后端一体，一次部署即用，无多后端管理模块。

## 四、部署说明

### Worker 部署

1. 登录 Cloudflare Dashboard → Workers 和 Pages → 创建 → 创建 Worker。
2. 把对应 `.js` 文件内容粘贴进在线编辑器（或通过 API / Wrangler 部署）。
3. 绑定 KV：创建 KV 命名空间，绑定变量名填 **`K`**。
4. 设置环境变量（见下表，仅填必填项）。
5. 部署，访问 `https://<名称>.<子域>.workers.dev/<入口>` 进入面板。

### Pages 部署

1. 创建 Pages 项目（高级模式 / 直接上传）。
2. 上传 `_worker.js`（分离版前端或单文件 Pages）。
3. 绑定 KV：变量名 **`K`**（生产 + 预览环境）。
4. 设置环境变量（仅填必填项）。
5. **注意顺序**：先建项目 → 设环境变量 → 绑定 KV → **最后部署**（绑定与环境变量只对之后新建的部署生效）。

### 登录与访问

- 入口路径由环境变量 `L`（等价 `login`）决定，例如 `L=admin` ⇒ 面板在 `/admin`。
- 首次访问面板会进入 **SETUP 页强制设置管理密码**（密码保存在 KV 中，之后可在面板内修改）。
- 密码也可用环境变量 `ADMIN` 强制覆盖（设置后面板内不可改）。
- 订阅地址为 `/<入口>/sub/clash|singbox|karing`，**无需登录**（客户端不带 cookie）。

## 六、订阅模式与优选

### 6.1 订阅模式

| 模式       | 说明                                            |
| -------- | --------------------------------------------- |
| `worker` | 下发 VLESS/Trojan/XHTTP 节点（默认 300 个）            |
| `masque` | 下发 MASQUE 节点（28 个端点，走 QUIC/UDP-443）           |
| `home`   | 下发家宽节点（VPN Gate OpenVPN + 自定义证书）              |

### 6.2 订阅地址

- `/<入口>/sub/clash` → Clash 订阅
- `/<入口>/sub/singbox` → sing-box 订阅
- `/<入口>/sub/karing` → Karing 订阅
- `/<入口>/sub?c=<格式>` → 面板预览用

### 6.3 地区与命名

节点名含地区标签（如 `CFNext-·1`），`preferredIPs` 支持国家码前缀、端口、`#标签` 后缀与多源逗号分隔。

## 七、性能优化与安全

- 订阅结果进程内缓存 60 秒，空值输出与旧版逐字节一致。
- `/sub` 反滥用限流（同 IP 60 秒内第 31 次起静默回欢迎页）。
- 反扫描：未匹配路径统一返回同一份欢迎页，字节一致、零提示。
- 指纹消隐：能力词消隐，用户身份+字节双随机差异化。
- 健康检查统一走 `https://www.gstatic.com/generate_204`，主组补 `expected-status: 204`。
- `cpuLimit` 默认关闭；Free 计划单请求硬上限 10ms。
